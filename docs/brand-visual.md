# opus55video 品牌视觉规范

## 品牌定位

opus55video 是以文字生成视频为核心的创作工作台。视觉概念是“放映室”：让影像占据主角位置，界面提供清楚、安静的创作控制。

## 标志

标志由暖白色圆环与铜色光点组成，表达镜头、光圈与日食。正式文件为 `public/logo.svg` 和 `public/favicon.svg`。展示时保留图形周围至少四分之一图标宽度的空白，不改变圆环比例，也不为图形叠加发光效果。

## 色彩

| 用途     | 深色主模式             | 浅色模式                |
| -------- | ---------------------- | ----------------------- |
| 背景     | `oklch(0.17 0.012 60)` | `oklch(0.97 0.009 78)`  |
| 文字     | `oklch(0.95 0.01 75)`  | `oklch(0.21 0.016 58)`  |
| 内容面板 | `oklch(0.22 0.013 60)` | `oklch(0.995 0.004 78)` |
| 主色     | `oklch(0.78 0.105 65)` | `oklch(0.49 0.105 57)`  |
| 分割线   | `oklch(0.36 0.014 63)` | `oklch(0.83 0.012 72)`  |
| 次要文字 | `oklch(0.72 0.017 70)` | `oklch(0.48 0.015 62)`  |

主色用于重要按钮、焦点、导航选中态与少量提示。大面积保留煤灰、暖白和影像本身的色彩。全局实现位于 `src/styles/globals.css`，首页的固定深色电影场景位于 `src/styles/opus-home.css`。

## 字体与层级

- 展示文字使用 Bebas Neue。用于首页主标题、工作台主标题和重要章节标题；控制在短句内。
- 正文和交互使用 DM Sans Variable。中文由系统无衬线字体回退，保证阅读清晰。
- 大标题保持紧凑行高，正文使用舒适行高。辅助信息用颜色和间距区分，不依赖大量全大写标签。

## 影像与版式

- 首页主画面使用宽银幕构图。主角与标题各占一侧，文字区保持足够暗度和对比度。
- 影像轻微降低饱和度，保留真实暗部与暖色高光。避免霓虹光晕、彩色渐变和无关的抽象装饰。
- 首页主视觉的边缘使用克制的胶片孔形态，这是品牌的识别元素。其他区块不重复该装饰。
- 功能内容使用清楚的边框和非对称节奏；编辑工作台优先保证提示词、选项和任务状态的可读性。

## 组件与交互

- 按钮和卡片使用小圆角（全局半径 `0.375rem`，品牌展示面可使用更直的 `3px` 边角）。
- 主要按钮使用铜色底与深色文字；次要按钮使用透明底与清晰边框。
- 输入框在深色与浅色主题中都使用可见边框、明确标签和焦点环。
- 动效只用于首页画面与标题的进入，以及交互反馈。遵循系统的减少动态效果设置。

## 页面应用

- 首页：宽银幕主视觉、功能矩阵、概念影像、创作流程与说明内容。
- `/create`：提示词创作台、比例与时长选择、创作提示、作品历史。
- 登录和注册：品牌背景、统一字形与表单卡片。
- `/settings` 与其他账户页面：统一的侧栏、主题色、卡片密度与标题层级。
- 定价页：沿用全局主题、品牌标题和直角卡片。
