# Behavior notes

- Reference announcement and navigation remain at the top on desktop. The mobile navigation is reduced to primary actions.
- Reference media cards act as links and horizontal rails. Promotional content cycles over time; this first version uses a stable original film frame because the user requested a first version and no campaign content was supplied.
- Reference cards use hover emphasis. opus55video uses subtle image scale and border emphasis on hover, while keeping all destinations visible without hover.
- On narrow screens, the concept frame rail scrolls horizontally; the menu opens on click. Motion respects `prefers-reduced-motion`.
- All homepage creation actions lead into the authenticated video workbench. The images are generated concept art and are labeled as such.
