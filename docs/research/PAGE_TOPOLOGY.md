# Higgsfield reference and opus55video first version

Reference inspected on 2026-09-30 at 1728px and 390px. The requested scope is a style reference for a new product, so this is an original, shorter homepage rather than a copy of Higgsfield content or media.

The reference has a vivid top announcement strip, compact dark navigation, a horizontally browsable media rail, dense product entry cards, large film-led feature sections, and a wide footer. On mobile, navigation condenses and card rails continue horizontally. The page uses near-black backgrounds, white type, lime calls to action, Inter and Space Grotesk.

opus55video translates this into: announcement strip, compact navigation, a cinematic hero frame, creative tool cards, original concept frame showcase, three-step workflow, final call to action, and footer. The signature is a letterboxed hero frame with large condensed type and frame metadata. Display font is Bebas Neue, body is DM Sans; the single bright lime accent is reserved for primary actions.

Reference screenshots: `docs/design-references/higgsfield-home-desktop.png` and `higgsfield-home-mobile.png`.
